# MyOS — Build Plan v2 (the re-cut)
*July 22, 2026 · supersedes the original build plan. Built against three locked artifacts: Feature List v1.1, UX Foundation v1 (incl. the Deck + four D's), and the Warm Glass design kit. The Milestone-0 skeleton (Vite + React + Supabase auth) already runs locally.*

## Standing laws (in DECISIONS.md from day one)

- All of TRUE's engineering law: optimistic writes, three-tier prompt caching, signature-gated judgment caching, RLS immutability, row-checks, length caps, injection framing, honest cursors, one lockfile.
- **The L5 countermeasure, now formal:** when a milestone stalls, the rule is *finish or formally cut* — never start the adjacent fun thing. A cut gets a dated DECISIONS entry.
- Keep the raw (Q2): originals archived beside every distillate.
- No scores, no streaks, no notifications, no proactivity (Q3) anywhere in V1.
- Design law = the kit: tonal wells, no borders/rings (focus = glow), marker A (dot + mono tag), one accent moment per screen, undo everywhere / confirm only for the permanent, the two-register voice, motion timing table.
- Project colors: user-choosable, random default, any hex.
- Day boundary: user's local timezone.

## M3 — Review (the re-cut, July 24: milestones map to rooms)
The read-only dossiers over M1's spine. At the silver dot: every world as a card — name, derived status line, honest momentum. In a world: the dossier — Goals with status · Recently (a dated ledger derived from what actually happened) · Next (drawn from the same queue React will work) · Waiting-on (arrives with People in M4). Everything derived, nothing maintained, **nothing tappable into action** — read-only is the feature; world cards only navigate. **Done = you check on any world in one glance without being asked to do anything about it.**

## M4 — React (the stack + the Line)
One stack of cards, one at a time — the four D's (→Do ↑Delay ←Delegate ↓Delete, drag physics per the design target) + the punch beneath. One queue: the Line — Deb speaks the top of it, Reflect windows it (two chips above the composer), React deals all of it; no second list anywhere, ever. Cards minted from the spine first (stale Bench items, tasks needing a verdict, broken rhythms); Delegate wires People/Waiting-On with chase dates; species-aware Delete. The from-people species (email/Slack/Teams) stays V2 behind the never-a-second-inbox bar. **Done = clear the verdicts, punch the moves, and "what now?" has one true answer everywhere.**
